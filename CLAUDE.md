# Трешка — игра «3 в ряд»

HTML5 Canvas + чистый JS (ES-модули), без сборки. Запуск: любой статический сервер в корне, например `python3 -m http.server`.

## Правила работы
- Читай `CONTRACTS.md` перед началом. Модули общаются через `game.bus`, без прямых импортов между папками `src/<модуль>`.
- Трогай только свою папку (см. зоны ниже) и `data/` по профилю. Общие файлы (`src/shared/*`, `src/main.js`, `CONTRACTS.md`) — минимальные правки, отдельными коммитами.
- Работай в своей ветке `feat/<зона>`, делай `git fetch origin main && git rebase origin/main` перед пушем. Мерж в `main` — только по просьбе пользователя.
- Проверки, тесты и запуск игры — только с разрешения пользователя.
- Не создавай и не собирай `obochina.html`.
- Код: ES-модули, без внешних зависимостей, комментарии коротко и по делу, русский язык в UI.

## Зоны
| Зона | Папки |
|---|---|
| Ядро | `src/core` |
| Механики | `src/mechanics` |
| Уровни и прогрессия | `src/levels`, `data/levels` |
| Визуал и UI | `src/render`, `src/ui`, `assets` (графика) |
| Звук | `src/audio`, `assets/audio` |
| Монетизация и мета | `src/meta` |
